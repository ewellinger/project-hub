# Files

- [Starting features and adding roles](feature-start-and-add.md) - How `hub feature start` and `hub feature add` create or adopt the hub branch, hub worktree, and per-role branches and worktrees through `ops::resolve::open_change`, roll back exactly what they created on failure, treat workspace and tmux steps as post-save warnings, and prompt for roles and branches in a terminal.
- [Frozen bases: freeze, unfreeze, and refreeze](frozen-bases.md) - How a feature pins a role's base to a fixed commit — the Pin record, reference worktrees versus pinned open changes, where pin commits come from, the freeze/unfreeze/refreeze transactions and their off-pin safeguard, how status, start, add, merged, set-base, finish, pull, and the repo commands treat pins, and the dashboard keys.
- [Hub init and repo registration](hub-and-repo-management.md) - How `hub init` creates a hub (and `--force` refreshes init-owned files), and how `hub repo add`, `set`, `remove`, `rename` (including `--records-only` repair), and `list` edit `hub.json` with one commit on main while keeping per-machine feature records consistent.
- [Review, merged, set-base, and finish](review-merged-finish.md) - The lifecycle commands that advance or close a feature's changes — `feature review`, `feature set-base`, `feature merged`, `feature finish` — including the dirty-worktree (exit 20) and in-use (exit 21, via lsof) refusals, adopted-worktree confirmation, tmux handling, irreversible-first ordering, and leftover-directory warnings.
- [Reviewing a merge or pull request](start-review.md) - How `hub feature start-review URL` turns a GitLab merge request or GitHub pull request into an isolated review feature — URL parsing and matching to exactly one role, reading the review through `glab api` or `gh api`, verifying the head, refusing forks, closed reviews, occupied or diverged branches and collisions, and conditional rollback.
- [Status, list, and pull](status-and-pull.md) - How `hub status` compares recorded feature or base state with git (rows, drift and exit 30, merge hints, base lag, the Completed table, JSON fields), how `hub feature list` summarizes features, and how `hub pull` fast-forwards checkouts concurrently while refusing anything that is not a clean fast-forward.
